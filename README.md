# Figures 公式サイトコンテナ



文芸誌 **Figures** を、有限会社デジタルリサーチの既存WordPressサイト内で公開・運用するための実装です。現在は、十分な素材が届く前でも構成と操作性を確認できる「入れ物」の段階です。



## このリポジトリの内容



`Figures_Website_Source.zip` に、次の一式を収録しています。



- デザインレビュー用の公開画面コンテナ
- 
- WordPress導入用プラグイン
- 
- 最新号、バックナンバー、お知らせを管理する専用画面
- 
- 編集担当者向けの導入・更新手順
- 
- 権利・個人情報の取扱いに関する注意
- 


> 作品本文、表紙原稿、著者情報、連絡先、認証情報は含めていません。素材未提供部分は「準備中」として実装しています。
> 


## WordPressへの導入



ZIPを展開し、`wordpress/figures-site-starter/README.md` の手順に従ってください。プラグインを有効化すると `/figures/` の公開ページと、Figures専用の編集メニューを準備します。



## 注意



この公開リポジトリでソースコードを共有することと、Figuresの表紙・作品本文・画像を公開することは別です。コンテンツを追加する前に、編集部で著作権・肖像権・個人情報の公開可否を確認してください。
